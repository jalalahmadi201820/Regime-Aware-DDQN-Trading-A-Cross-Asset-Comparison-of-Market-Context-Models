# Regime-Aware-DDQN-Trading-A-Cross-Asset-Comparison-of-Market-Context-Models
Research code comparing market regime context models within a fixed DDQN trading framework across Bitcoin, Ether, and a composite of 28 DJIA30 stocks. Includes Gaussian and Poisson HMMs, K-means, XGBoost, RNN, LSTM, and 1D-CNN.
